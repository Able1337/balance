# Баланс

Мобильное статическое PWA без сборки, сервера и регистрации. Русский интерфейс, настройки из пяти полей, календарь, дневные записи, пять графиков, офлайн и резервные копии JSON.

## GitHub Pages
1. Загрузите содержимое этой папки в корень репозитория (включая `.nojekyll`).
2. Откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Откройте выданный HTTPS-адрес. После первого успешного открытия приложение доступно офлайн.
4. Android: меню браузера → Установить приложение. iPhone: Safari → Поделиться → На экран «Домой».

Приложение использует относительные пути и работает в подпапке репозитория. PNG-иконки включены. Для локального просмотра используйте HTTP-сервер, например `npx serve .`. При открытии index.html как файла установка и офлайн недоступны.

## Расчёт
План пересчитывается каждый календарный месяц от даты старта. Для 31 числа в коротком месяце используется последний день месяца; затем дата возвращается к исходному числу. Вес для периода — последнее взвешивание строго до начала периода, поскольку запись веса считается итогом дня. При отсутствии нового веса используется предыдущий. Базовый обмен = 10 × вес периода + 6,25 × рост − 5 × возраст на начало периода + 5. Расход = базовый обмен × 1,2 / 1,35 / 1,55, либо введённый вручную расход. Дневной дефицит периода = (вес периода − цель) × 7700 / оставшиеся на начало периода дни, минимум ноль. Изменение старых записей пересчитывает зависимые периоды.

Прогресс = (начальный вес − последний измеренный вес + дефицит за дни после последнего взвешивания / 7700) / (начальный вес − цель). При отсутствии взвешиваний используется дефицит с начала плана. Зелёный сегмент — измеренное снижение, жёлтый — расчётный вклад калорий после взвешивания. Профицит уменьшает прогресс. Остаток калорий использует ту же модель. Процент ограничен 0–100.

Календарь: зелёный — дефицит достиг плана дня, жёлтый — положительный, но ниже плана, красный — ноль или профицит. Процент недели = фактический дефицит / сумму планов прошедших дней недели от начала плана до дедлайна; незаполненные дни дают нулевой вклад. На границе месяца учитывается вся неделя, включая соседний месяц.

Белок: по выбору пользователя 1,6 г/кг веса месячного периода. Коэффициент можно изменить в «Мой план». Пунктир на графике — цель, зелёная точка — достигнута, жёлтая — ниже цели. Графики равномерно располагают записи; пропуски дат видны в таблицах значений.
## Данные
localStorage `balance-v1`, отдельно для каждого браузера и адреса. Синхронизации нет. Делайте резервные копии в разделе «Мой план». Импорт заменяет текущие данные после подтверждения и проверки файла. Хранилище содержит дату рождения и измерения; не размещайте экспорт в публичном репозитории.

Внешний шрифт Manrope необязателен: при отсутствии сети используется системный шрифт. Формулы перенесены из пользовательской таблицы, приложение не подбирает медицинские рекомендации. Версия концепта 1.
